# GreenLeaf – Organic Plant Store

A responsive static landing page for GreenLeaf, an organic plant store.
Built with plain HTML, CSS and JavaScript.

## Features
- Header with navigation and mobile menu
- Hero, About, Plant Categories, Why Choose Us, Contact and Footer sections
- Shop with category filter, search and sorting
- Add to cart drawer, wishlist and quick view (demo only, no payments)
- Responsive on desktop, tablet and mobile

## Colour palette
`#005F02` `#427A43` `#C0B87A` `#F2E3BB`

## Run locally
Open `index.html` in a browser.

## Deploy
Import this repository in Vercel (no build settings needed) to publish the site.
